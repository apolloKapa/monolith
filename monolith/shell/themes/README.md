Colour themes (Settings → Theme → Style → Colours). Each file is a palette: base, mantle, crust,
surface0–2, overlay0–2, text, subtext0–1 and the accent colours.

These palettes come from the earlier Monolith, which was based on Serpantinum by @ilyamiro
(GNU AGPL-3.0); they are kept here as data under that licence. Well-known schemes (Ayu, Nord,
Catppuccin, Gruvbox, Dracula, …) are their authors' published palettes.
